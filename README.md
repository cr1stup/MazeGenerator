# Генератор и решатель лабиринтов
Проект представляет собой консольную программу для генерации лабиринтов и поиска пути в них.

В основе генерации лежат модифицированные рекурсивный алгоритм и алгоритм Краскала, которые выдают неидеальные лабиринты с различными поверхностями.


Типы поверхностей:
* монетка ('C')
* ловушка ('T')

Монетка уменьшает общую стоимость пути, ловушка — увеличивает.

 Для поиска оптимального пути реализованы алгоритмы Беллмана-Форда и алгоритм SPFA (Shortest path faster algorithm), которые находят оптимальный путь, учитывая отрицательные веса и обрабатывая циклы отрицательной длины.


## Использование 
1. Запустить программу из файла \src\main\java\backend\academy\Main.java

2. Следуя текстовому интерфейсу выбрать:

    * высоту и ширину генерируемого лабиринта
    * используемый алгоритм генерации лабиринта
    * точку начала и конца пути
    * используемый алгоритм поиска пути

3. Получить визуализацию исходного лабиринта и найденного в нем пути


## Алгоритмы генерации
### Kruskal Algorithm
#### Описание

Алгоритм Краскала начинается с добавления каждой клетки в отдельное множество, затем случайным образом соединяются соседние клетки, если они принадлежат разным множествам. В результате все множества объединяются, пока не останется только одно, которое и будет представлять проход в лабиринте, окруженный стенами.

#### Реализация
Генерация лабиринта реализована в функции generate, логика которой в следующем:

1. Создаем список всех возможных ребер между клетками и перемешиваем его;
2. Инициализируем все стены в лабиринте;
3. Перебираем перемешанные ребра и, если две клетки, которые соединяет это ребро, уже принадлежат одной и той же группе (соединены каким-то путем), ребро пропускается, иначе удаляем это ребро, соединяя две клетки и создавая проход;
4. Отдельной функцией делаем лабиринт неидеальным, добавляя дополнительные соединения для создания циклов;
5. Отдельной функцией расставляем специальные поверхности в лабиринте. 

Для реализации алгоритма созданы два внутренних класса: Edge, который представляет ребро (стенку) между ячейками и UnionFind для объединения ячеек (создания прохода). 

### Recursive Algorithm
#### Описание
Алгоритм использует обход в глубину (dfs) для создания лабиринта, где каждая клетка последовательно посещается, а стены между ними удаляются по мере движения.

#### Реализация
Генерация лабиринта реализована в функции generate, логика которой в следующем:

1. Заполняем все клетки стенами;
2. С клетки (1, 1) запускаем функцию dfs, которая выбирает случайную соседнюю, которая еще не посещена, удаляет стену между текущей и новой клеткой и для нее рекурсивно повторяет процесс;
3. Отдельной функцией делаем лабиринт неидеальным, добавляя дополнительные соединения для создания циклов;
4. Отдельной функцией расставляем специальные поверхности в лабиринте. 

## Алгоритмы поиска пути
#### Описание
Алгоритм SPFA основан на алгоритме Беллмана-Форда, поэтому многие функции вынесены в базовый класс, от которого наследуются оба алгоритма.

Основная логика реализована в функции checkDirections, в которой для текущей клетки проверяются все соседние с попыткой улучшить кратчайшее расстояние, при этом делается проверка на наличие цикла в текущем пути.

### Bellman-Ford Algorithm
1. Задаем расстояние до старта как 0, а до всех остальных клеток — "бесконечность";

2. K-1 раз проверяем (K — количество клеток без стены), можно ли уменьшить текущее кратчайшее расстояние до каждой клетки. Если можно, то обновляем значение и запоминаем клетку из которой пришли, при этом делая проверку на наличие цикла в текущем пути;

3. Отдельной функцией воссоздаем путь из конечной клетки, двигаясь по сохраненным клеткам кратчайшего пути, пока не достигнем начальной.  

### Shortest Path Faster Algorithm 
Алгоритм SPFA является оптимизированной версией Беллмана-Форда. Вместо постоянной проверки всех клеток — клетки берутся из очереди, в которую добавляются, только если расстояние до них было уменьшено. Это делает данный алгоритм эффективнее оригинальной версии.
